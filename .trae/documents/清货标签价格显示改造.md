# 清货标签价格显示改为普通标签方式

## 需求

清货标签的价格显示改为和普通标签一样的大金额格式：
- `$` 符号 + 整数部分大字体 + 小数点 + 小数部分小字体
- 右对齐排列

## 当前 vs 目标

### 当前清货价格
```kotlin
val clearancePriceBitmap = textToBitmap("$${formatMoney(clearancePrice)}", fontSizeToPixels(28f), ...)
// 单一字体，整体一个位图
```

### 目标（普通标签方式）
```kotlin
val price = formatPriceParts(clearancePrice)
val priceIntegerBitmap = textToBitmap(price.integer, fontSizeToPixels(40f), true, "sans-serif-black")
val priceDotBitmap = textToBitmap(".", fontSizeToPixels(20f), true, "sans-serif-black")
val priceDecimalBitmap = textToBitmap(price.decimal, fontSizeToPixels(20f), true, "sans-serif-black")
val priceCurrencyBitmap = textToBitmap("$", fontSizeToPixels(20f), false, "sans-serif-black")
// 分4个位图，整数部分40px大字体，其他20px
```

## 修改

**文件**: `/Users/sean/DEV/HbwebExpo/HbwebExpoApp/android/app/src/main/java/com/hbweb/expo/HbPrinterModule.kt`

**位置**: `buildClearanceLabelCommand` 方法，第 ~466-503 行

1. 将 `clearancePriceBitmap` 拆分为 4 个位图（currency, integer, dot, decimal）
2. 用 `formatPriceParts(clearancePrice)` 格式化价格
3. 名称最大宽度计算改为扣除 4 个价格位图的总宽度
4. 价格排列改为右对齐拼接（参照普通标签方式）
5. 移除旧的单一 `clearancePriceBitmap`
