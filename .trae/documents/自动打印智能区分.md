# 自动打印按扫码关键字匹配条码

## 需求

自动打印时，根据扫码的关键字（条码）来匹配对应的子条码，打印匹配到的那个条码的标签。

## `smartAutoPrint` 函数逻辑

```
扫码关键字: "9525812580371"
→ smartAutoPrint("9525812580371", detail)
→ 在商品详情中逐个匹配:

1. setCodes.find(item => item.setBarcode === "9525812580371")
   匹配到 → 打印套装标签(条码=9525812580371, 零售价=对应零售价) × printQuantity

2. multiCodes.find(item => item.barcode === "9525812580371")
   匹配到 → 打印多码标签(条码=9525812580371, 零售价=对应零售价) × printQuantity

3. clearancePrice.clearanceBarcode === "9525812580371"
   匹配到 → 打印清货标签 × printQuantity

4. 都不匹配 → 打印普通标签(主条码) × printQuantity
```
