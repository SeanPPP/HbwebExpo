# 标签打印添加小标签开关

## 需求

在标签打印区域添加"小标签"开关按钮，默认关闭。打开后：
- **普通标签**和**折扣标签**按宽度 60mm 打印
- 其他标签（清仓、大折扣）不受影响

## 技术背景

- 打印通过 `HbPrinterModule` Android 原生模块完成
- `printBigDiscountLabel` 已支持 `printType` 参数模式
- 60mm ≈ 472 dots（200 DPI）
- 原生模块不在当前仓库，但已支持 printType 参数传递

## 修改方案

参照 `printBigDiscountLabel` 的 printType 模式，给普通标签和折扣标签也添加 printType 参数，传入 `"small"` 表示小标签模式。

### 修改 1：`native.ts` — 添加 printType 参数

**文件**: `/Users/sean/DEV/HbwebExpo/HbwebExpoApp/src/modules/printer/native.ts`

```typescript

export async function printNativeDiscountLabel(payload: ProductLabelPrintPayload) {
  await ensureBluetoothPermissions();
  return getModule().printDiscountLabel(payload);

// 改后

  await ensureBluetoothPermissions();
  return getModule().printProductLabel(payload, printType ?? null);
}

export async function printNativeDiscountLabel(payload: ProductLabelPrintPayload, printType?: string | null) {
  await ensureBluetoothPermissions();
  return getModule().printDiscountLabel(payload, printType ?? null);
}
```
