# 清货标签改造：取消清货普通标签 + 位图方式重做清货标签

## 需求

1. **取消"清货普通标签"（clearanceProduct）按钮** — 移除该功能
2. **清货标签改为位图方式打印** — 参照折扣标签的位图方式
3. **标签尺寸 78×26mm** — 约 614×205 dots (200 DPI)
4. **条码使用二维码** — 用 QR Code 替代 CODE128 一维码

## 当前 vs 目标

### 当前清货标签（CPCL 文本指令）
- 尺寸 570×400 (≈72×50mm)
- CODE128 一维码
- 纯 CPCL 文本指令绘制
- 价格使用 SETMAG 放大文本

### 目标清货标签（位图方式）
- 尺寸 614×205 (≈78×26mm)
- QR Code 二维码
- 使用 textToBitmap + bitmapCommand 位图方式
- 折扣价格大小的字体显示清货价

**新的清货标签布局** (78×26mm = 614×205 dots)：

```
┌─────────────────────────────────────────────────────────────┐
│ 商品名称(2行)                    清货价 $12.34               │
│ ITEM:12345 SUP:ABC               was: $15.00                │
│ [QR Code 64×64]    Clearance    2026-05-20                  │
└─────────────────────────────────────────────────────────────┘
```

位图方式实现要点：
- 使用 `textToBitmap` 生成所有文本位图
- 使用 `createQrCodeBitmap` 生成二维码
- 清货价使用大字体（参照折扣标签的 `fontSizeToPixels(44f)` 或适当大小）
- `was:` 价格使用较小字体 + 删除线效果
- 宽度 614，高度 205
