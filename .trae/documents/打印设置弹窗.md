# 打印设置 UI 改造

## 需求

1. 打印设置放在 SearchPanel 最后一行显示
2. 包含：自动打印开关、小标签开关、打印数量、单次/连续有效开关
3. 所有设置不持久化，随页面刷新重置

## UI 布局（SearchPanel 最后一行）

```
┌────────────────────────────────────────────────────┐
│ [搜索输入框........................] [🔍] [×]       │
│ 自动打印 [Switch]  小标签 [Switch]  数量 [1] [−][+] │
│                       单次有效 [Switch]             │
└────────────────────────────────────────────────────┘
```

- **自动打印**：扫码命中后自动打印（当前已有）
- **小标签**：普通/折扣标签按 60mm 宽度打印（当前在 LabelPrintCard）
- **数量 [1] [−][+]**：打印份数，默认 1，范围 1-99
- **单次有效 [Switch]**：
  - 开启（默认）：打印一次后数量重置为 1
  - 关闭：数量保持设置值，连续打印都使用相同份数

## 打印数量逻辑

### 单次有效（quantitySingleUse = true，默认）
1. 用户设置数量为 3
2. 扫码 → 自动打印 3 份
3. 打印完成后 → printQuantity 自动重置为 1
4. 下次扫码 → 打印 1 份

### 连续有效（quantitySingleUse = false）
1. 用户设置数量为 3
2. 扫码 → 自动打印 3 份
3. 打印完成后 → printQuantity 保持 3
4. 下次扫码 → 仍然打印 3 份
